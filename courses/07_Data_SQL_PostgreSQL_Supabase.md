# AI ENGINEERING — PARTIE 07
## Data, SQL, PostgreSQL et Supabase

Créer le cursus Data + Database avec PostgreSQL et Supabase comme terrain central.

Commencer par données, tables, lignes, colonnes, types, entités, relations, schémas, clés primaires, clés étrangères, contraintes et normalisation 1NF/2NF/3NF.

SQL : SELECT, WHERE, ORDER BY, GROUP BY, HAVING, INSERT, UPDATE, DELETE, agrégations, JOIN, sous-requêtes, UNION/INTERSECT/EXCEPT, CTE, window functions, transactions.

PostgreSQL avancé : indexes B-tree/GIN/GiST, views, materialized views, functions, triggers, VACUUM, EXPLAIN, rôles, permissions et performance.

Supabase : PostgreSQL managé, Auth, RLS, Storage, Realtime, Edge Functions, migrations et API générée.

Projet fil rouge : modéliser un restaurant réel : recettes, ingrédients, fournisseurs, commandes, stock, prix, ventes, fiches techniques.

Ne jamais traiter Supabase comme une simple interface graphique : toujours expliquer PostgreSQL et les mécanismes sous-jacents.

Preuve finale : schéma complet + requêtes SQL + RLS + API + tests de sécurité.

### RÈGLE PÉDAGOGIQUE
Modèle mental → définition technique → fonctionnement → exemple → code → erreur volontaire → debug → test → sécurité → performance → architecture → exercice → preuve.
