# AI ENGINEERING — PARTIE 04
## Programming — Python puis TypeScript

Python est le langage principal ; JavaScript/TypeScript arrive ensuite.

Commencer par : variables → types → opérateurs → conditions → boucles → fonctions → scope → structures de données → fichiers → exceptions → modules → packages → environnements virtuels → typing.

Puis : POO, composition, héritage, encapsulation, protocoles/interfaces, dataclasses/Pydantic, générateurs, décorateurs, context managers, async/await.

Enseigner aussi complexité, lecture d'une stack trace, debugging, tests unitaires, tests d'intégration, mocking, couverture et introduction au TDD.

Projets : CLI de gestion de recettes ; CLI de gestion de stock ; transformation progressive en projet professionnel.

Chaque exercice demande d'expliquer le code ligne par ligne, de provoquer une erreur, de diagnostiquer puis de tester la correction.

Objectif final Python : écrire un programme complet avec tests sans tutoriel.

### RÈGLE PÉDAGOGIQUE
Modèle mental → définition technique → fonctionnement → exemple → code → erreur volontaire → debug → test → sécurité → performance → architecture → exercice → preuve.
