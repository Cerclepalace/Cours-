# AI ENGINEERING — PARTIE 02
## Systems — comprendre l'ordinateur

Crée le cursus « Systems » depuis zéro.

Enseigne CPU, RAM, stockage SSD/HDD, GPU, cache, processus, threads, mémoire virtuelle, fichiers, OS, kernel, permissions et I/O.

Modèle mental : CPU = cuisinier ; RAM = plan de travail ; disque = réserve/chambre froide ; OS = chef d'orchestre.

Passe ensuite au niveau technique : fetch → decode → execute, hiérarchie de mémoire, processus, allocation mémoire, virtualisation de mémoire et rôle du kernel.

Premier module : comprendre ce qui se passe quand on lance `python mon_programme.py`.

Inclure observation réelle de la machine, exercices PowerShell et Linux/WSL, expériences CPU/RAM/disque, diagnostic de lenteur, sécurité, performance, mini-projet « Mon ordinateur en une page » et preuve de compétence.

Les chiffres de latence sont des ordres de grandeur dépendant du matériel.

### RÈGLE PÉDAGOGIQUE
Modèle mental → définition technique → fonctionnement → exemple → code → erreur volontaire → debug → test → sécurité → performance → architecture → exercice → preuve.
