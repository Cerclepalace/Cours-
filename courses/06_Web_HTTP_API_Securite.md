# AI ENGINEERING — PARTIE 06
## Web, HTTP, API et sécurité applicative

Construire progressivement : Client → réseau → HTTP → serveur → API → base de données → réponse.

Couvrir IP, DNS, ports, TCP/UDP à niveau utile, HTTP/HTTPS, requête/réponse, méthodes, status codes, headers, JSON, REST, CRUD, authentication, API keys, JWT, sessions, OAuth à niveau conceptuel, CORS, validation, erreurs et OpenAPI.

Utiliser Python pour consommer des APIs puis FastAPI pour en construire une.

Projet : API complète de gestion de recettes.

Chaque notion doit être observable avec des requêtes réelles. Faire volontairement des erreurs de statut HTTP, de JSON, d'authentification et de validation, puis apprendre à les diagnostiquer.

Faire comprendre clairement la différence frontend/backend/API/database.

### RÈGLE PÉDAGOGIQUE
Modèle mental → définition technique → fonctionnement → exemple → code → erreur volontaire → debug → test → sécurité → performance → architecture → exercice → preuve.
