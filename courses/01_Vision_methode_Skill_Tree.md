# AI ENGINEERING — PARTIE 01
## Vision, méthode et Skill Tree

Prompt de création de cours — progression from zero → AI System Engineer

### PROMPT À UTILISER
Construis le parcours complet « AI Engineering — From Zero → AI System Engineer ».

Public : jeune cuisinier ayant déjà construit une base de données importante, mais voulant reconstruire les fondamentaux proprement.

Principe : expliquer comme à un enfant de 5 ans, sans simplifier la technologie. La pédagogie doit être simple ; la rigueur technique doit rester élevée.

Objectifs :
- établir la carte complète des compétences ;
- montrer les dépendances ;
- distinguer ce qui est fondamental, secondaire et avancé ;
- utiliser les statuts UNKNOWN → LEARNING → UNDERSTOOD → PRACTICED → VALIDATED → MASTERED ;
- exiger une preuve de compétence avant de considérer une notion acquise ;
- privilégier compréhension → observation → code → casse volontaire → debug → test → mesure → documentation.

Le parcours doit couvrir : Systems, Terminal, Programming, Git/GitHub, Web/API, Data/Database, Supabase, Cloud/Infra, Mathematics, ML, Deep Learning, LLM, RAG, Agents et AI Engineering.

Ne commence pas directement par les LLM. Construis d'abord les fondations et explicite les dépendances critiques.

### RÈGLE PÉDAGOGIQUE COMMUNE
Pour chaque notion : modèle mental → définition technique → fonctionnement → exemple → code → erreur volontaire → debug → test → sécurité → performance → architecture → exercice → preuve de compétence.

### PROJET FIL ROUGE
Restaurant Intelligence Platform : faire évoluer progressivement les compétences vers un système réel reliant données, PostgreSQL/Supabase, API et IA.
