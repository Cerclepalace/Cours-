# AI ENGINEERING — PARTIE 08
## Cloud, déploiement et mathématiques pour l'IA

### PARTIE CLOUD
Linux serveur ; Docker ; conteneurs ; images ; volumes ; réseaux ; variables d'environnement ; secrets ; déploiement ; logs ; monitoring ; coûts ; services managés.

Relier chaque concept à l'architecture réelle : application → API → PostgreSQL/Supabase → services IA.

Ne pas commencer par Kubernetes. Il doit être traité comme une compétence ultérieure.

### PARTIE MATHS
Enseigner ce qui sert réellement à comprendre l'IA, sans superficialité : fonctions ; graphes ; vecteurs ; produit scalaire ; matrices ; dérivées ; gradients ; probabilités ; statistiques ; distributions ; optimisation.

Pour chaque notion : intuition → représentation visuelle → formule → exemple numérique → code Python → application IA.

Preuve : implémenter et expliquer une descente de gradient simple.

### RÈGLE PÉDAGOGIQUE
Modèle mental → définition technique → fonctionnement → exemple → code → erreur volontaire → debug → test → sécurité → performance → architecture → exercice → preuve.
