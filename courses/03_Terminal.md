# AI ENGINEERING — PARTIE 03
## Terminal — parler directement à l'ordinateur

Crée le cursus « Terminal / Command Line ».

Enseigne Bash et PowerShell en partant du modèle mental du système de fichiers et des processus.

Couvrir : shell ; navigation ; chemins absolus/relatifs ; création, déplacement, copie et suppression ; recherche ; lecture de fichiers ; permissions ; utilisateurs ; variables d'environnement ; pipes ; redirections ; processus ; scripts ; SSH ; gestion de packages ; Python/pip ; npm ; commandes utiles pour Git, PostgreSQL, Supabase et Docker.

Chaque commande doit être expliquée : ce qu'elle fait, pourquoi elle existe, ce que l'OS fait derrière et comment vérifier le résultat.

Projet fil rouge : script qui organise automatiquement des fichiers de recettes.

Exiger des exercices de diagnostic et de casse volontaire. Le but est de rendre l'élève autonome dans un terminal, pas de lui faire mémoriser une liste de commandes.

### RÈGLE PÉDAGOGIQUE
Modèle mental → définition technique → fonctionnement → exemple → code → erreur volontaire → debug → test → sécurité → performance → architecture → exercice → preuve.
